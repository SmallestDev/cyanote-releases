# Cyanote

Releases of **Cyanote**, a personal music player for PC and Android.

## Download
Open the [latest release](https://github.com/SmallestDev/cyanote-releases/releases/latest) and download:
- `Cyanote-windows-<version>.zip` for Windows
- `Cyanote-android-<version>.apk` for Android

## Updates
Both apps include an automatic update system.

When a new version is released, the apps check for updates when launched and download the latest version automatically. On Android, tap "Install" when asked.

## Installation
### Windows
1. Download `Cyanote-windows-<version>.zip`
2. Extract all files
3. Run `Cyanote.exe`

> Do not run the app directly inside the ZIP file. Extract it first.

### Android
1. Download `Cyanote-android-<version>.apk` on your phone
2. Open it and allow installing from this source once
3. Keep Cyanote running on your PC, connect the phone to the same Wi-Fi, and tap "PC 자동으로 찾기"

## Notes
The Android app plays music through the Cyanote app on your PC, so the PC app must be running.

If you encounter a problem, please report it so it can be fixed in a future update.
