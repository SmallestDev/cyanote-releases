# Mononote

Releases of **Cyanote**, a personal music player for PC and Android.

## Download
Open the [latest release](https://github.com/SmallestDev/cyanote-releases/releases/latest) and download:
- `Cyanote-Setup-<version>.exe` for Windows
- `Cyanote-android-<version>.apk` for Android

## Updates
Both apps include an automatic update system.

When a new version is released, the apps check for updates when launched and download the latest version automatically. On Windows, the update is applied when you restart Cyanote or while it isn't in use, in the same place, so your shortcuts and taskbar pin keep working. On Android, tap "Install" when asked.

## Installation
### Windows
1. Download `Cyanote-Setup-<version>.exe`
2. Run it. Cyanote installs for your account only (no administrator rights needed) and adds Desktop and Start menu shortcuts.
3. To keep it on the taskbar, right-click the Desktop shortcut and choose "Pin to taskbar" (on Windows 11: "Show more options" → "Pin to taskbar").

> Windows may show "Windows protected your PC" because the installer isn't signed. Choose **More info** → **Run anyway**.

To uninstall, open Settings → Apps → Cyanote. Your library is kept, so reinstalling picks up where you left off.

`Cyanote-windows-<version>.zip` is used by the automatic updater. You don't need to download it.

### Android
1. Download `Cyanote-android-<version>.apk` on your phone
2. Open it and allow installing from this source once
3. Sign in with the same account you use on your PC

## Notes
The phone app works on its own. The PC app is only needed for PC features such as sending files from your PC to your phone.

If you encounter a problem, please report it so it can be fixed in a future update.
